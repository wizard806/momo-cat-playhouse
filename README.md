# 橘子的小小捣蛋日

原创第一人称 3D 小猫探索游戏，支持手机 Safari 触屏操作。

游戏地址：https://wizard806.github.io/momo-cat-playhouse/

左边摇杆移动，右边划屏转头。抓取键拿起物品；拿着时轻点近抛，按住再松手远抛。拍打键推动小物件、挠沙发和敲铃，跳跃键登上家具。完成五个小心愿后可继续探索。进度保存在当前浏览器。

1.1 更新：移动与转头更平滑，起跳和落地有缓冲反馈；持物保留家具碰撞，杯罐可打碎，毛线球会弹跳，沙发会留下爪痕。奶奶会绕家具走、听声查看、招手或摸头。暂停菜单的“整理物品”能恢复物品并保留心愿，旧版进度继续使用。

电脑：WASD/方向键移动，拖动画面转头，E 抓取/抛出，F 拍打，空格跳跃，Escape 暂停。

所有模型和音效由本项目程序生成，不使用 I Am Cat 的代码、美术或声音。Three.js 和 cannon-es 随包提供，许可证见 vendor 目录。

本仓库仅包含可公开运行的静态游戏文件，无账号凭据、原版 APK 或逆向分析数据。

开发检查：Node.js 下运行 `npm test` 和 `npm run check`，用本地静态服务器打开页面。机制测试覆盖摇杆死区、平滑、投掷力度和家具寻路。浏览器验证已完成五项任务、轻抛/蓄力抛、贴墙持物、暂停取消蓄力、破碎、抓痕、招手、整理保留进度与横竖屏布局；iPhone 真机双指操作与帧率仍需设备体验。

## 1.2 三关探索

主菜单和暂停菜单可直接选择客厅、厨房、院子，无需解锁或登录。厨房新增开冰箱、送鱼点心、投球入锅、木台登高和归还故事书；院子新增三次蝴蝶追逐、撞倒木罐、送玩具、四级石台和风铃。每关五项任务，完成后可去下一关或自由探索。当前目标提示适合家长陪孩子阅读，投掷目标保留走近放置的辅助方式。

第一关继续使用原存档键；新关分别存于 orange-playhouse-chapter-2 / 3。重新开始只清除当前关。此版本不包含原版资源，也不承诺原版所有剧情或画面。参考依据为已留存安卓版的 Unity 元数据声明和官方商店介绍：https://play.google.com/store/apps/details?id=com.NewFolderGames.IAmCat 。声明只能证明结构，不能恢复方法体或实际物理参数。
