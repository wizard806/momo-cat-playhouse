# Interaction Upgrade Implementation Plan

**Goal:** 改善现有免费小猫游戏的操作手感、物品互动和角色动作，继续使用原 GitHub Pages 地址。

**Architecture:** 保留现有 Three.js/cannon-es 场景和五项任务。只在输入、持物物理、物品反馈、人物状态与动画处改动；增加可独立验证的摇杆、平滑和屋内寻路函数。全部依赖仍随站点分发。

**Tech Stack:** JavaScript ES modules、Three.js 0.160.1、cannon-es 0.20.0、Node 内置测试、浏览器输入验证。

## 已确认设计

用户选择保留三个主按钮；拿起后轻点抛出，按住再松手扔得更远。先改手感和互动，不扩建关卡或改托管。没有血量/失败惩罚；原来的进度存储键保持兼容。

## 实施与验收

1. 输入和平滑：摇杆死区、按时间衰减的转头与加减速、起跳缓冲、落地反馈。验证细小摇杆抖动不移动，快慢帧率下平滑一致，桌面与触屏仍可移动/跳上家具。
2. 物品：准星辅助与遮挡检查、真实碰撞的抓取、轻抛/蓄力抛掷、杯罐破碎、毛线球弹性、挠沙发痕迹、铃铛动画。验证不能隔家具抓物，持物撞墙不会穿墙，取消操作不会误扔，整理物品不清空心愿。
3. 角色：猫爪交替拍打/双爪持物/投掷/落地；奶奶平滑转身、听声查看、绕家具走、俯身查看与招手/摸头。验证各动作有可观察反馈且奶奶不穿过家具。
4. 回归：五项任务可完成；老存档可读；暂停/继续/重玩与横竖屏可用；无控制台错误。
5. 发布：在干净远端基线基础上提交，等 Pages 成功，校验实际发布文件，再检查正式链接。保留 iPhone 真机手感尚需用户体验的边界。
